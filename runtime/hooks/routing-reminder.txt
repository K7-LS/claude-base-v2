⚠ Роутинг-гейт (похоже на доменную задачу).

Запрос напоминает содержательную доменную задачу — генерацию или правку артефакта: спецификация / ВОР / расчёт / подбор оборудования / смета / КП / УПД / письмо / акт ИД / ответ экспертизе / раздел ПД-РД.

До начала работы выполни роутинг-гейт (CLAUDE.md, «Архитектура: main → domain agent → auditor»):
1. Напиши первой видимой строкой: «Роутинг: <домен> → агент <имя>» либо «Роутинг: инлайн — <почему ни один доменный агент не подходит>».
2. Есть доменный агент — работу делает он (Task, subagent_type = имя файла агента), а не main-агент и не general-purpose. Агента выбирай по его description.
3. Перед выдачей артефакта — обязательный ревьюер (auditor или профильный валидатор); его вердикт с доказательствами.

Если это не задача-генерация (просто вопрос или диалог) — игнорируй это напоминание.
